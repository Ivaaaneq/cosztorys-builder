# 🏗️ CosztorysBuilder

**Professional Cost Estimator for Construction Services**

A modern web application for generating professional cost estimates (kosztorysy) for construction and renovation projects in Poland. Built with vanilla JavaScript, HTML5, and CSS3.

---

## ✨ Features

- 📋 **Project Management** - Create estimates with project name and location
- 🔧 **10+ Services** - Pre-configured services with Podlasie region pricing
- 🔍 **Smart Search** - Filter services by keywords
- 📊 **Auto Calculation** - Automatic cost calculations with variants
- 🎯 **Price Variants** - STANDARD and PREMIUM (+30%) options
- 📄 **PDF Export** - Generate professional PDFs ready to send to clients
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile
- 🎨 **Modern UI** - Clean, professional interface

---

## 🚀 Quick Start

### Online (Recommended)
Visit the live app: [CosztorysBuilder on Netlify]

1. Clone the repository:
```bash
git clone https://github.com/Ivaaaneq/cosztorys-builder.git
cd cosztorys-builder
```

2. Open `index.html` in your browser (or use Live Server)

## 📝 How to Use

1. **Enter Project Details**
   - Project name and location
   - Auto-filled with current date

2. **Select Services**
   - Check services you need
   - Enter quantity in m² (or other units)
   - Use search to find services quickly

3. **Calculate**
   - Click "Oblicz kosztoprys" (Calculate Estimate)
   - View cost breakdown and variants

4. **Export**
   - Choose STANDARD or PREMIUM pricing
   - Click "Pobierz PDF" to download professional PDF

5. **Send to Client**
   - PDF is ready to email or print

## 📊 Pricing Notes

All prices are based on **Podlasie region (Poland)** market rates as of 2026.
